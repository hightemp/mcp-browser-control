# Установка расширения Browser Extension Tool

## Пошаговая инструкция

### 1. Подготовка иконок (опционально)

Если у вас установлен ImageMagick или Inkscape, создайте PNG иконки:

```bash
cd icons
chmod +x create_icons.sh
./create_icons.sh
```

Если нет, расширение будет работать и без PNG иконок (Chrome покажет стандартную иконку).

### 2. Установка расширения в Chrome

1. **Откройте Chrome** и перейдите по адресу:
   ```
   chrome://extensions/
   ```

2. **Включите режим разработчика**:
   - В правом верхнем углу найдите переключатель "Режим разработчика"
   - Включите его

3. **Загрузите расширение**:
   - Нажмите кнопку "Загрузить распакованное расширение"
   - Выберите папку `chrome-extension` из этого проекта
   - Нажмите "Выбрать папку"

4. **Проверьте установку**:
   - Расширение должно появиться в списке установленных
   - Убедитесь, что оно включено (переключатель в положении "Вкл")

### 3. Использование расширения

1. **Запустите серверы**:
   ```bash
   # Из корневой папки проекта
   ./start_system.sh
   ```

2. **Откройте любую веб-страницу** в Chrome

3. **Откройте DevTools**:
   - Нажмите F12 или
   - Правый клик → "Просмотреть код" или
   - Меню Chrome → Дополнительные инструменты → Инструменты разработчика

4. **Найдите вкладку "Browser Tool"**:
   - В DevTools найдите вкладку "Browser Tool"
   - Если её нет, попробуйте перезагрузить страницу

5. **Подключитесь к серверу**:
   - Нажмите кнопку "Подключиться"
   - Статус должен измениться на "Подключено"

6. **Используйте команды**:
   - Попробуйте нажать "Получить HTML страницы"
   - Результат появится в правой панели

## Возможные проблемы

### Расширение не появляется в списке

- Убедитесь, что выбрали правильную папку `chrome-extension`
- Проверьте, что в папке есть файл `manifest.json`
- Попробуйте перезагрузить страницу расширений

### Вкладка "Browser Tool" не появляется в DevTools

- Перезагрузите веб-страницу
- Закройте и откройте DevTools заново
- Убедитесь, что расширение включено в chrome://extensions/

### Не удается подключиться к серверу

- Убедитесь, что серверы запущены (`./start_system.sh`)
- Проверьте, что порты 8080 и 8894 не заняты другими процессами
- Попробуйте перезапустить серверы

### Команды не выполняются

- Убедитесь, что подключение к серверу установлено
- Проверьте консоль DevTools на наличие ошибок
- Убедитесь, что content script загружен (должно быть сообщение в консоли)

## Отладка

### Логи расширения

1. Откройте chrome://extensions/
2. Найдите "Browser Extension Tool"
3. Нажмите "Подробности"
4. Нажмите "Просмотреть представления: background page"
5. Откроется консоль background script

### Логи content script

1. Откройте DevTools на любой странице
2. Перейдите на вкладку Console
3. Ищите сообщения от "Content script"

### Логи панели DevTools

1. Откройте DevTools
2. Перейдите на вкладку "Browser Tool"
3. Откройте DevTools для DevTools (Ctrl+Shift+I)
4. Проверьте консоль на ошибки

## Удаление расширения

1. Перейдите в chrome://extensions/
2. Найдите "Browser Extension Tool"
3. Нажмите "Удалить"
4. Подтвердите удаление
