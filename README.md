# MCP Browser Extension Tool

Этот проект представляет собой MCP (Model Context Protocol) сервер, который взаимодействует с расширением браузера Chrome через WebSocket для автоматизации действий в браузере.

## Архитектура

```
┌─────────────────┐    WebSocket     ┌─────────────────┐    MCP Protocol    ┌─────────────────┐
│  Chrome         │ ◄──────────────► │  Go MCP Server  │ ◄─────────────────► │  MCP Client     │
│  Extension      │   ws://localhost │  (main.go)      │   SSE/STDIO        │  (Claude, etc.) │
└─────────────────┘      :8090/ws    └─────────────────┘                    └─────────────────┘
```

## Компоненты

### 1. Chrome Extension (`chrome-extension/`)
Расширение браузера, которое:
- Подключается к WebSocket серверу на `ws://localhost:8090/ws`
- Выполняет команды на веб-страницах
- Предоставляет DevTools панель для ручного управления
- Поддерживает автоматическое переподключение

**Основные файлы:**
- `manifest.json` - конфигурация расширения
- `background.js` - WebSocket менеджер и обработка команд
- `content.js` - взаимодействие с DOM страницы
- `panel.js` - DevTools панель для ручного управления
- `popup.js` - popup интерфейс расширения

### 2. MCP Server (`main.go`)
Go сервер, который:
- Запускает WebSocket сервер для связи с расширением
- Предоставляет MCP инструменты для автоматизации браузера
- Поддерживает SSE и STDIO транспорты для MCP клиентов
- Логирует все операции

## Поддерживаемые команды

### 1. `browser_get_html`
Получить HTML содержимое текущей страницы браузера.

**Параметры:**
- `tabId` (опционально) - ID вкладки браузера

### 2. `browser_get_html_by_selector`
Получить HTML элементов по CSS селектору.

**Параметры:**
- `selector` (обязательно) - CSS селектор для поиска элементов
- `tabId` (опционально) - ID вкладки браузера

### 3. `browser_click_element`
Кликнуть по элементу на странице.

**Параметры:**
- `selector` (опционально) - CSS селектор элемента для клика
- `index` (опционально) - индекс элемента, если найдено несколько (по умолчанию 0)
- `coordinates` (опционально) - объект с координатами `{x: number, y: number}`
- `tabId` (опционально) - ID вкладки браузера

*Примечание: необходимо указать либо `selector`, либо `coordinates`*

### 4. `browser_input_data`
Ввести данные в поле ввода на странице.

**Параметры:**
- `selector` (обязательно) - CSS селектор поля ввода
- `value` (обязательно) - значение для ввода
- `index` (опционально) - индекс элемента, если найдено несколько (по умолчанию 0)
- `clear` (опционально) - очистить поле перед вводом (по умолчанию true)
- `tabId` (опционально) - ID вкладки браузера

### 5. `browser_get_console_log`
Получить логи консоли браузера.

**Параметры:**
- `tabId` (опционально) - ID вкладки браузера

### 6. `browser_get_network_log`
Получить network логи браузера.

**Параметры:**
- `tabId` (опционально) - ID вкладки браузера

### 7. `browser_send_command`
Отправить произвольную команду в расширение браузера.

**Параметры:**
- `command` (обязательно) - название команды
- `data` (опционально) - данные команды
- `tabId` (опционально) - ID вкладки браузера

## Установка и запуск

### 1. Установка расширения Chrome

Следуйте инструкциям в файле `chrome-extension/INSTALL.md`.

### 2. Запуск MCP сервера

```bash
# Установка зависимостей
go mod tidy

# Запуск с SSE транспортом (по умолчанию)
go run main.go

# Запуск с STDIO транспортом
go run main.go -t stdio

# Настройка портов
go run main.go -ws_port 8090 -p 8896 -h 0.0.0.0
```

**Параметры запуска:**
- `-t` - тип транспорта: `sse` (по умолчанию) или `stdio`
- `-h` - хост SSE сервера (по умолчанию `0.0.0.0`)
- `-p` - порт SSE сервера (по умолчанию `8896`)
- `-ws_port` - порт WebSocket сервера (по умолчанию `8090`)

### 3. Подключение MCP клиента

#### SSE транспорт
```
URL: http://localhost:8896/sse
```

#### STDIO транспорт
```bash
go run main.go -t stdio
```

## Использование

### Через MCP клиент (например, Claude Desktop)

```json
{
  "mcpServers": {
    "browser-tool": {
      "command": "go",
      "args": ["run", "/path/to/main.go"],
      "env": {}
    }
  }
}
```

### Через DevTools панель

1. Откройте Chrome DevTools (F12)
2. Перейдите на вкладку "Browser Tool"
3. Нажмите "Подключиться"
4. Используйте интерфейс для выполнения команд

## Разработка

### Структура проекта

```
.
├── main.go                    # MCP сервер
├── go.mod                     # Go модуль
├── go.sum                     # Go зависимости
├── README.md                  # Документация
└── chrome-extension/          # Расширение Chrome
    ├── manifest.json          # Конфигурация расширения
    ├── background.js          # Background script
    ├── content.js             # Content script
    ├── popup.html/js          # Popup интерфейс
    ├── panel.html/js/css      # DevTools панель
    ├── devtools.html/js       # DevTools интеграция
    ├── icons/                 # Иконки расширения
    └── INSTALL.md             # Инструкции по установке
```

### Добавление новых команд

1. Добавьте новую структуру аргументов в `main.go`
2. Создайте новый инструмент в функции `registerBrowserTools()`
3. Реализуйте типизированный обработчик
4. Добавьте поддержку команды в `background.js` расширения
5. При необходимости добавьте логику в `content.js`

## Безопасность

- WebSocket сервер принимает соединения только с localhost
- Расширение работает только с разрешенными доменами
- Все команды логируются для аудита
- Поддержка CORS для WebSocket соединений
